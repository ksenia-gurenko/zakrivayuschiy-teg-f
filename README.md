# 🎨 Zakrivayuschiy Teg - Финальный проект по вёрстке

<img width="1778" height="1000" alt="image" src="https://github.com/user-attachments/assets/8ca08ef6-b1c4-49ad-ac5c-c542653a32cf" />

**Современный адаптивный лендинг** с комплексной анимацией и темизацией

## 🌟 Ключевые особенности

### 🛠 Технологический стек
- **HTML5** (семантическая вёрстка)
- **CSS3** (Grid + Flexbox)
- **SCSS/SASS** (препроцессинг)
- **BEM** (методология именования)
- **Адаптивный дизайн** (mobile-first)
- **Доступность** (ARIA, WCAG)
- **Оптимизация производительности**

### ✨ Реализованные функции
| Категория       | Функционал                                                                 |
|-----------------|---------------------------------------------------------------------------|
| **Адаптивность** | Полноценная поддержка всех разрешений (320px+)                           |
| **Анимации**    | 60fps-оптимизированные трансформации и переходы                          |
| **Темы**        | Light/Dark режим с системным определением (`prefers-color-scheme`)       |
| **Интерактив**  | Модальные окна (`<dialog>`), кастомные состояния (:hover, :focus-visible)|
| **Типографика** | Переменные шрифты (Inter) + пиксельный шрифт (PressStart2P)              |

## 🎯 Выполненные требования

### ✅ Базовые требования
```diff
+ Pixel-perfect соответствие макету
+ Кросс-браузерность (Chrome, Firefox, Yandex)
+ Отсутствие горизонтального скролла
+ Стабильная сетка на всех брейкпоинтах
🖼 Медиа и шрифты
Адаптивный SVG-фавикон (меняет цвет в Dark Mode)

CSS-фильтры для изображений

Два кастомных шрифта:

Inter (variable font)

PressStart2P (ретро-стиль)

🎨 Управление темами
scss
:root {
  --bg-primary: #fff;
  --text-primary: #000;
  /* ... */
}

@media (prefers-color-scheme: dark) {
  :root {
    --bg-primary: #000;
    --text-primary: #fff;
  }
}
🔥 Интерактивные элементы
Анимированные кнопки с mix-blend-mode

Модальное окно на <dialog>

Состояния:

:hover - плавное затемнение

:focus-visible - доступный фокус

:active - эффект нажатия

✨ Сложные анимации
Анимация сердца включает:

Изменение цвета

Масштабирование

"Искры" через ::after/::before

Оптимизацию через will-change

css
.heart {
  transition: transform 0.3s ease;
  will-change: transform;
}
